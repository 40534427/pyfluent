一、功能概述
----------------------------------------------------------------------------
本工具从 params.json 读取参数，生成 LS-DYNA .k 输入文件、run_solver.bat、
以及 build_log.json（记录参数快照 + 网格统计 + 与上次变更 diff）。

v2 新增：
  ✓ 伞绳分段数（line_segments）可参数化  (原模板固定 10 段 → 可改 3~50)
  ✓ 网格控制参数集中在 mesh_control 分组，一眼看清所有影响网格数量的参数
  ✓ build_log.json 自动记录参数变更与网格总量统计
  ✓ 伞衣壳数 = 模板拓扑固定（15024 节点 / 13056 四边形）

二、目录结构
----------------------------------------------------------------------------
  params.json            ← 所有可调参数（中文注释）
  make_kfile.exe         ← Windows 下双击即可生成（需先 build_windows.bat）
  Parachute_generated.k  ← 已预生成的默认参数 K 文件
  run_solver.bat         ← 已预生成的求解器启动脚本
  build_log.json         ← 生成后自动产生（含网格统计与参数变更 diff）
  build_windows.bat      ← Windows 一键打包 make_kfile.exe
  build_linux.sh         ← Linux/macOS 一键打包
  src/                   ← 源代码（纯标准库，可直接 `python3 paramk/generator.py` 运行）

三、快速开始
----------------------------------------------------------------------------
1) 编辑 params.json（修改任意参数的 "值" 字段）
2) 运行 make_kfile.exe  （或 python3 src/paramk/generator.py --params params.json）
3) 新 K 文件、run_solver.bat、build_log.json 自动生成在当前目录
4) run_solver.bat 复制 run_parachute.exe 到同目录后双击即可计算

五、build_log.json 示例
----------------------------------------------------------------------------
每次 make_kfile.exe 运行后，会在 K 文件同目录产生 build_log.json，
其中 "参数变更diff" 数组记录了与上次运行相比所有值发生变化的参数：

  "参数变更diff": [
    {"参数": "suspension_lines.line_segments", "旧值": 10, "新值": 20},
    {"参数": "fluid_domain_in_k.box_nx",       "旧值": 20, "新值": 10},
    {"参数": "inflow_air.Vy",                  "旧值": 220, "新值": 250}
  ]

"网格统计" 分组包含结构/流体的节点数、单元数、伞绳总长度等，
"总计" 分组给出 K 文件总节点/总单元数，方便快速评估计算规模。

六、Windows 打包 make_kfile.exe
----------------------------------------------------------------------------
1) 安装 Python 3.10+（勾选 Add to PATH）
2) 双击 build_windows.bat
3) 等待编译完成（首次约 1 分钟）
4) make_kfile.exe 出现在本目录下（约 7~8 MB，零依赖）

七、源码运行（开发调试）
----------------------------------------------------------------------------
  cd src/paramk
  python3 generator.py --params ../../params.json --outdir ../

八、文件清单
----------------------------------------------------------------------------
  params.json          — 79+ 参数，10 分组，每项含值/单位/说明/可调标记
  _template.pkb.gz     — 内嵌网格模板（伞衣 15024 节点 / 13056 壳；伞绳
                         方向节点 + beam 链；共 ~190 KB gz）
  generator.py         — 纯标准库 K 生成器（gzip / struct / math / json）
  build_template.py    — 从原始 .k 反演模板的开发脚本（dev 用）
  Parachute_generated.k— 预生成的默认参数 K（4.5 MB）
