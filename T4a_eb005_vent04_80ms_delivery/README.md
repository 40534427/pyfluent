# T4a 工况交付包（80 ms）

ALE / 罚函数耦合降落伞充气求解器，T4 方案第一组：膜松弛纤维 + 顶孔加强环，本次把仿真从 60 ms 延长到 80 ms。

## 工况定义

| 参数 | 值 | 说明 |
|---|---|---|
| 网格 | nx=16, ny=28, nz=16 | 自动圆柱 ALE 网格，5824 单元 |
| 终止时间 | 0.080 s | 29836 步，wall 2445 s |
| tssfac | 0.8 | 显式安全系数 |
| 膜本构 | `--tension-only-membrane` | 松弛纤维：受压方向应力置零（*MAT_FABRIC 语义） |
| 环向模量 | `--eb-frac 0.05` | eb = 0.05·ea |
| 顶孔约束 | `--vent-radius 0.04` | 顶孔节点串接 tension-only 加强环，L0=2π·0.04/16≈0.0157 m，初始松弛 |
| 流固耦合 | 默认 CLLS | pfac=0.1，ileak 默认，无额外阻尼 |

## 复现

```bash
bash run_T4a.sh                  # 结果写入 results_rerun/
bash run_T4a.sh input/Parachute_F28.k out_80ms
```

依赖：Python 3、numpy、scipy、matplotlib。源码在 `src/`（`run_parachute.py` + `aleparachute/`）。

## 结果（80 ms）

| 指标 | 数值 |
|---|---|
| 锚点合力峰值 | **3752 N @ 66.8 ms** |
| 锚点合力 40–60 ms 均值 | 1841 N |
| 锚点合力 60–80 ms 均值 | **2942 N** |
| 锚点合力 50–80 ms 均值 | 2676 N |
| 锚点合力末值（80 ms） | 2762 N |
| 伞衣平均半径 R（history） | 0.130 m（峰值 0.135 m @ 70 ms） |
| 伞衣外轮廓最大半径（VTK 99.5%） | 0.167 m |
| 顶孔半径 | 0.0565 m（目标 0.04，环梁被拉伸约 41%） |
| 伞衣高度 h | 0.194 m |
| h/R（按轮廓 R=0.167） | **1.16** |
| 膜面积 | 末值 0.147 m²（峰值 0.152 m² @ 68.8 ms） |

### 与 60 ms 版对比

| 指标 | 60 ms | 80 ms | 趋势 |
|---|---|---|---|
| 锚点力峰值 | 2876 N @ 43.5 ms | 3752 N @ 66.8 ms | ↑ 30%，**超出 2500–2900 N 目标带** |
| 50–60 ms 均值 | 2152 N | 2143 N | 持平（同段一致，结果可复现） |
| 60–80 ms 均值 | — | 2942 N | 新增区间，载荷维持高位 |
| 末值 | 2463 N | 2762 N | ↑ 12% |
| 平均半径 R（history） | 0.107 m | 0.130 m | ↑ 21%，仍缓慢充气 |
| 轮廓半径（VTK） | 0.135 m | 0.167 m | ↑ 24% |
| h/R（VTK） | 1.53 | 1.16 | ↓ 伞衣变扁、横向张开 |
| 膜面积 | 0.135 m² | 0.147 m² | ↑ 9% |

### 判据结论

1. **R 继续增长**：60→80 ms，轮廓半径 0.135→0.167 m（+24%），平均半径 0.107→0.130 m，说明充气尚未饱和，伞衣仍在张开。
2. **h/R 明显下降**：1.53→1.16，伞衣从"长筒/深碗"转为更扁的碗形，是展开过程的正常形态演化；h 本身略降（0.207→0.194 m）。
3. **膜面积仅增 9%**（0.135→0.147 m²），说明 60 ms 后主要不是新增展开面积，而是形状重分布（横向扩张、高度下降）。
4. **力峰值不达标**：66.8 ms 出现 3752 N 峰值，比 60 ms 版高 30%，超过约 2500–2900 N 的期望上限。这是本 80 ms 工况的主要问题——延长仿真暴露了后期载荷峰，而非收敛。
5. 顶孔持续被拉伸至 0.0565 m（超目标 41%），环梁刚度仍偏软。

## 交付内容

- `input/Parachute_F28.k` — 原始 LS-DYNA 关键词文件
- `results/history.csv` — 逐步诊断（时间、R、高度、压强、锚点合力、膜面积等）
- `results/line_force.csv` — 16 条伞绳底端张力时间历程
- `results/final_structure.vtk` / `final_fluid.vtk` — 终态结构/流场
- `results/state_*_structure.vtk` — 每 10 ms 的伞衣状态帧（0–80 ms，用于变形渲染）
- `results/run.log` — 完整求解日志
- `figures/canopy_deform_T4a_eb005_vent04_80ms.png` — 侧视+俯视变形过程图
- `figures/T4a_anchor_force_area_80ms.png` — 锚点合力与膜面积曲线
- `figures/line_tension_T4a_eb005_vent04_80ms.png` — 伞绳张力与汇聚点合力曲线
- `src/` — 求解器与绘图脚本（`plot_canopy_deform.py`、`plot_tension.py` 可直接重绘）

## 备注

- 顶孔加强环为 tension-only 弹性索，仅提供环向约束、不承受压力；目标半径 0.04 m 是初始松弛长度，实际孔径随膜拉伸增大。
- 80 ms 的 50–60 ms 区间与 60 ms 版完全重合（均值 2143 vs 2152 N），说明两次运行在同一物理轨道上，60 ms 后的差异来自真实的后续演化。
- 后续建议：若要压住 66.8 ms 的 3752 N 峰值，可提高顶孔环刚度/降低目标半径（0.03 m），或对锚点附近膜单元增加局部阻尼；同时继续算到 100 ms 确认载荷是否回落。
